# 漂流瓶置頂話題功能設計方案

## 目標

- 於「月光漂流瓶」頁面新增置頂話題 Banner，提升討論度與互動。
- 支援官方主題與精選用家瓶子兩種置頂模式，並可於後台靈活設定。

---

## 1. 前台 UI/UX 設計

### 1.1 置頂 Banner 位置
- 擺放於「月光漂流瓶（把話說給大海聽...）」副標題下方、功能橫條（投瓶｜撈瓶｜尋瓶）上方。

### 1.2 樣式建議
- 半透明底色，帶微光外框（參考「心事」Tab 條發光線）。
- 長條 Banner，支援橫向滾動（走馬燈）或精緻扁身設計。
- 響應式設計，確保不壓縮「投瓶輸入框」可見度。

### 1.3 內容格式
- 官方主題：
  > 今夜星空焦點：「你遇過最反白眼嘅 Les 圈渣女行為係...？」 [已有 42 人投瓶回應]
- 精選瓶子：
  > 船長今晚撈到最震撼嘅瓶子：「同前度一齊 3 年，啱啱先知佢瞞住我結咗婚...」 即刻入去一齊傾

---

## 2. 互動邏輯

### 2.1 點擊 Banner 行為
- 官方主題：
  - 自動篩選/預選相關標籤（如 #放負），顯示該主題瓶子。
- 精選瓶子：
  - 跳至該瓶子詳情或留言串。

### 2.2 回應數即時更新
- Banner 內容如有回應數，需即時更新（AJAX 請求獲取最新數據）。

---

## 3. 後台管理功能

### 3.1 設定項目
- 置頂話題內容
- 類型（官方/精選）
- 關聯標籤
- 精選瓶子 ID
- 回應數
- 主題切換（手動/自動）

### 3.2 API/設定檔
- 前台載入時請求 API 取得最新置頂話題設定。
- 若精選瓶子，需能指定瓶子 ID 並自動抓取內容摘要。

---

## 4. 驗證與優化

- 手動測試不同裝置下 Banner 顯示與互動。
- 驗證點擊 Banner 能正確篩選/跳轉。
- 後台切換主題後，前台能即時同步。
- 不影響原有「投瓶」輸入框可見度與體驗。
- 多裝置響應式測試通過。

---

## 5. 延伸建議

- Banner 內容支援 emoji/小圖標，提升吸引力。
- 精選瓶子如有圖片/多媒體，後續可擴展展示。
- 後台管理介面如未有，建議先用 config/JSON 檔，後續再補視覺化介面。

---

## 6. 相關檔案

- public/drift-bottle.html — 插入 Banner 區塊
- public/css/drift-bottle.css — 新增 Banner 樣式
- public/js/drift-bottle.js — 控制 Banner 行為、互動
- src/pages/api/bottle/topic.js（或 config/setting.js）— 後台 API/設定

---

## 7. 驗收標準

- 前台 Banner 正確顯示，樣式符合預期。
- 點擊 Banner 能自動篩選主題/跳轉精選瓶子。
- 後台切換主題，前台能即時更新。
- 不影響原有「投瓶」輸入框可見度與體驗。
- 多裝置響應式測試通過。
